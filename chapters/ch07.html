第7章 ・ 約15分 ・ スマホ（Android）の Koala Sampler（無料の機能だけ）

書き出して完成

最後の章です。第6章で通して演奏できるようになった曲を、1つの音楽ファイルにします。ファイルになれば、家族に聞かせたり、ほかのアプリで使ったりできます。

7-1

演奏を録音する

やってみる
  1. MENU → RECORD SONG を選ぶ（録音の待ち状態になる）。AUTO-PLAY（第6章）を入れておくと、手で切り替えなくても最後まで流れます
  2. PERFORM の画面で再生を押すと、録音が始まる
  3. 構成表の順にシーケンスを切り替え、エフェクトもかけながら最後まで演奏
  4. 停止すると録音が止まるので、名前をつけて保存する
最後の音の響きまで録りたいときは、終わりに空のシーケンス（何も入っていない枠）へ切り替えてから止めると、余韻が切れません（公式マニュアルのコツ）。

何が起きたか

演奏したとおりに、切り替えもエフェクトも含めて、まるごと1つの音になりました。何度でもやり直せるので、気に入る演奏が録れるまで挑戦してOKです。

それの名前

演奏をまるごと録ることをレコーディング、録った完成品をトラックや音源と呼びます。公式マニュアルのクイックガイドでは、RECORD SONG の録音は WAV で保存されると説明されています。

7-2

ループを書き出す

やってみる

お気に入りのシーケンスを選んで、MENU → EXPORT → いまのシーケンスを、種類 MIXED・形式 WAV で書き出します。保存先を選ぶ画面が出たら、迷わず Download などを選んでください。

もう1つの遊び：MENU → RESAMPLE LOOP を選ぶと、いまのシーケンスが1つの音になって、空いているパッドに入ります。ループを1つの音として、さらに切ったり逆再生したりできます。

何が起きたか

1小節ぶんのループが、全部の音を混ぜた1つのファイルになりました。演奏しなくても、きっちり同じ長さのループが手に入ります。

それの名前

アプリの外に向けてファイルを作るのがエクスポート（書き出し）。全部の音を混ぜた1つのファイルにするのが MIXED、パッドごとに別のファイルにするのがステムです。自分で作ったループを、また材料としてサンプリングし直すのをリサンプリングといいます。

7-3

曲まるごとを残す

やってみる

MENU → EXPORT の中の Share Koala Song で、作業中の曲まるごと（パッドの音もシーケンスも全部）を1つのファイルにして、スマホに保存してください。公式マニュアルによると、Android 版には Koala 専用のフォルダがあり、スマホの「ファイル」アプリから見えるので、バックアップにも使えます。

何が起きたか

名前の最後が「.koala」のファイルができました。これがあれば、スマホを買い替えても、ほかの端末の Koala でも、続きから作業できます（MENU → LOAD の IMPORT SONG で読み込み）。

それの名前

作業の途中を丸ごと保存したファイルをプロジェクトファイルといいます。完成した WAV（聞く用）と、.koala（直す用）の2つを残しておくのが安心です。

できるようになったこと

    このあと

    • もう1曲：MENU → NEW で新しい曲を。2曲めは、たぶん半分の時間でできます
    • 有料の機能：高さを変えても長さが変わらない STRETCH、ドラムの自動切り分け（AUTO-CHOP）、ピアノロールなどは「Samurai」、トラックごとのエフェクトは「Mixer」で使えるようになります（公式マニュアル「In-App Purchases」より）
    • MIDI キーボードで弾く：Koala の設定の MIDI には、Bluetooth MIDI の接続ボタンがあります（公式マニュアルより）。MIDI 対応の鍵盤を持っていれば、パッドを鍵盤から鳴らせます
