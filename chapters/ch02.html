第2章 ・ 約30分 ・ iPad の Koala Sampler（無料の機能だけ）

音を集める

サンプラーは、音を集めるところから始まります。集め方は3通り。アプリに入っている音を借りる、マイクで録る、ファイルを読み込む。この章で3つとも試して、パッドを埋めていきます。

この章の最後に、ビートの材料（キック・スネア・ハイハットなど）がパッドにそろった状態になります。第3章以降はこの材料で進めます。

2-1

入っている音を借りる

やってみる
  1. SAMPLE の画面で、バンク B に切り替える（A は次の節で使うので空けておく）
  2. 右下あたりの SAMPLES を開き、BASICS の中をのぞく
  3. 気になる音を選んで聞いてみる。気に入ったら、空いているパッドへ指で引っぱる（または選んで LOAD）
  4. 余裕があれば、KIT の一覧から1つ選んで LOAD KIT
LOAD KIT は、いま表示しているバンクの16個をまるごと上書きします（公式マニュアルより）。空のバンクで使ってください。

何が起きたか

空だったパッドに、ドラムやベースなどの音が入りました。BASICS には約250の音が種類ごとに並んでいて、KIT を使うと16個がドラムセット一式として一度に入ります。

それの名前

アプリに用意された音の棚をライブラリ、16個ひと組のドラムセットをキットといいます。

借りた音でも、このあと切ったり高さを変えたりして自分の音にできます。プロも、ライブラリの音を材料にするのは普通のことです。

2-2

声と身の回りの音を録る

やってみる

バンク C に切り替えて、空いているパッドを押しっぱなしにしたまま、声を出してください。離すと止まります。

録るもののアイデア：「ドン」「ツ」「パッ」と口で言う（ボイスパーカッション）／手を叩く／机をノックする／コップを指ではじく／子どもの「わー！」

録れたら、そのパッドを叩いて聞いてみます。もう1つ、FX を選んでから録ると、声が変わります（ロボット声・低い声など8種類）。

ヘッドホンをしていないときに、録っている音を聞きながら録る設定（MONITOR）を入れると、キーンというハウリングが起きることがあります。

何が起きたか

押していた間の音が、そのままパッドに入りました。叩くたびに、同じ声が何度でも、すぐに鳴ります。口で言った「ドン」も、パッドに入れるとちゃんとドラムの役目をはたします。

それの名前

音を録って楽器として使えるようにすることをサンプリングといいます。録るときに音を加工するのはインプットエフェクト（Koala の FX）。

録った音の頭やおしりに余計な部分が入っていても大丈夫。第3章で切り取ります。

2-3

ファイルから読み込む

やってみる

この教材オリジナルの素材キットです。▶で試聴、⬇で iPad に保存できます（ブラウザの中で合成した音なので、自由に使ってOK）。まずはキック・スネア・ハイハット（閉）の3つを保存してください。

保存したら Koala で：

  1. バンク A に切り替えて、空いているパッドを選ぶ
  2. MENU → IMPORT AUDIO
  3. 保存したファイルを探して選び、LOAD
  4. 3つともバンク A に入れる（おすすめの場所：キック＝1、スネア＝2、ハイハット＝3）
Safari で保存したファイルは、ふつうは「ファイル」アプリの ダウンロード フォルダに入ります（Safari の設定で場所を変えられます）。Koala の読み込み画面で見つからないときは、SAMPLES の ADD LOCATION でそのフォルダを追加してください。 要確認チェックで記録する

何が起きたか

iPad に保存した音のファイルが、パッドに入りました。ほかのアプリで作った音、パソコンから送った音、友だちにもらった音も、同じ方法で取り込めます。

それの名前

外のファイルを取り込むことをインポートといいます。今回の素材は WAV（ワブ）という、音をそのまま記録した形式のファイルです。

動画から音だけを取り出す IMPORT VIDEO もあります（MENU の中）。

章末課題

材料をそろえる

耳で当てる：これはどの音？

素材キットの音が1つ鳴ります。名前を当ててください。6問中5問でクリア。ビートを作るときの「言葉」になります。
