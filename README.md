# コアラ・ラボ

スマホ（Android）の Koala Sampler（無料の機能だけ）で、1曲のビートを完成させる初心者向け教材（全7章・約3時間）。ビルド不要の静的サイト。

## 手元で動かす

`起動.bat` をダブルクリック（http://localhost:8766/ が開く）。スマホで使うには GitHub Pages などで https 公開する。

## 作り

- FM-1 ラボ（`../fm1-lab`）の部品を一部コピーして使っている：`synth.js` `fx.js` `notes.js` `store.js`（保存場所の名前だけ `koalalab.` に変更）
- `js/core/klesson.js`：章ページの共通部品。Koala の中はブラウザからのぞけないので、「やってみる」は本人が「やってみた」を押して開く。判定できるのはブラウザ側のクイズ・耳の課題・チェックリスト
- `js/core/kit.js` / `wav.js`：教材オリジナルの素材（ブラウザで合成 → WAV で保存 → Koala にインポート）

## 事実確認

操作手順は公式マニュアル https://manual.koalasampler.com/mobile/ で確かめる。マニュアルに書かれていないボタン位置などは `js/core/checks.js` の VERIFY に「分からないこと・なぜ・確かめ方・確かめると」を書いて、本文に `<div data-verify="id">` を置き、推測で書かない。マニュアルの文章はそのまま写さず、自分の言葉で書く。

## 記録を消さないための決まり

FM-1 ラボと同じ（課題IDは変えない・消さない、変えるなら `chapters.js` の `TASK_ALIASES`、保存は `store.js` 経由、テストは `?sandbox`）。

## 公開前の確認（スモークテスト）

1. `起動.bat` で開き、URL に `?sandbox` を付ける（紫の帯が出る＝本物の記録に触れない）
2. 全7章を開き、各章の「やってみた」・クイズ・ブラウザの課題・チェックリストを一通りクリアする
3. 目次の「ファイルに書き出す」→ いったん各章の「この章の記録を消す」→「ファイルから読み込む」で、記録が戻るか確かめる
4. 要確認チェックで1つ記録 → コピー → 「記録を消す」→ 控え（trash）に残っているか（書き出しファイルに入る）
5. サーバーを止めて読み込み直し、オフラインで全章が開くか
6. 最後に、テスト用の記録（`koalalab-sandbox.` で始まる保存）を消す
